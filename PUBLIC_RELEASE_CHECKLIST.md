# Public release checklist

- [x] Central provenance index committed on 2026-10-10
- [x] Historical full source and certificate SHAs indexed where available
- [x] Scope and limitations recorded
- [ ] Review full Git history and workflow logs for secrets and personal data
- [ ] Confirm redistribution rights for all source code and external attachments
- [ ] Materialize exact Lean source trees for selected frozen SHAs
- [ ] Reproduce historical CI and axiom audits; attach logs and source hashes
- [ ] Verify original commit author and commit timestamps against public records
- [ ] Confirm DOI/version for each actual public artifact
- [ ] Set this repository visibility to PUBLIC through GitHub Settings
- [ ] Independently check visibility from an unauthenticated session

Do not flip all source repositories to public without reviewing their complete history. A public repository exposes its code and history, not just the current working tree.
